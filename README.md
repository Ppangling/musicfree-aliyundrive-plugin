musicfree-aliyundrive-plugin

把阿里云盘当音乐库来放歌

源：

本插件仅供个人学习研究使用，请勿用于任何商业用途。
使用即表示你已了解并遵守阿里云盘的用户协议。

---

一、这是什么

把阿里云盘当音乐库来放歌：

· 榜单：根目录下的每一个一级子文件夹会自动变成一张榜单
· 全部音乐：根目录（含所有子目录）里的全部音频文件会聚合到「全部音乐」这一张榜单里
· 搜索：在上述音频里按文件名做关键词搜索

支持的格式：mp3 / flac / m4a / aac / wav / ogg / ape / wma / opus / m4b / aiff / dsf

云盘目录结构约定

插件读取的根目录由用户变量 PARENT_FILE_ID 指定，其一级子文件夹会成为榜单：

```text
PARENT_FILE_ID（配置的根目录）
├── 周杰伦 - 晴天.mp3        ← 直接放在根目录的歌曲，进入「全部音乐」可见
├── 华语流行/                ← 一级子文件夹，会成为「榜单」之一
│   ├── 林俊杰 - 江南.mp3
│   └── 陈奕迅 - 浮夸.flac
├── 欧美经典/                ← 另一个「榜单」
│   └── ...
└── 我的收藏/                ← 又一个「榜单」
    └── ...
```

文件名建议采用 歌名 - 歌手 - 专辑（可选）.扩展名 的格式（短横线两侧要有空格），插件会自动拆分出歌名与歌手；不按此格式命名时，整段文件名会作为歌名、歌手显示为「未知歌手」。

---

二、配置项说明

进入插件详情页，在用户变量中填写。四项均可留空，留空时自动使用插件内置默认值。

1. Refresh Token

获取步骤：

1. 浏览器登录 <a href="https://www.alipan.com/" target="_blank">阿里云盘网页版</a>
2. 按 F12 打开开发者工具 → 切换到 Application（应用） 面板
3. 左侧展开 Local Storage → 点击 www.alipan.com（若显示为 aliyundrive.com 同样操作）
4. 在右侧键值列表中找到 token 项，其值为一段 JSON 字符串
5. 从该 JSON 中提取 refresh_token 字段的值（不是复制整段 JSON）
6. 格式为 32 位小写字母数字组合，复制时不带引号、空格或换行

插件会在成功刷新后把新的 refresh_token 写入本地存储，无需手动维护。
若你在用户变量里显式填写了 refresh_token，插件会优先使用你填的值，不会覆盖。

2. Device ID

可填任意 32 位十六进制串，例如：

```text
0123456789abcdef0123456789abcdef
```

留空则使用插件内置默认值。

3. Drive ID

通常不需要修改，保持默认即可；仅当你需要挂载其他云盘时才调整。

4. 根目录 File ID

通常不需要修改，保持默认即可；仅当你需要更换根目录时才调整。

该目录下的一级子文件夹会成为榜单，目录内的全部音频会成为「全部音乐」。

修改根目录后，旧目录的缓存会自动失效，无需手动清缓存。

三、常见问题

Q：提示「刷新 token 失败」怎么办？
A：说明 refresh_token 已失效。请按第三节步骤重新获取，并更新到用户变量中。

Q：榜单分组能显示，但点进去没有歌曲？
A：一般是网络或权限问题。打开插件管理页的日志，查看是否出现 请求 /adrive/v3/file/list 失败 之类的报错。

Q：搜索结果不全 / 列表没更新？
A：插件对文件列表有 60 秒缓存。改动云盘内容后，等待 60 秒再操作，或重启 App 即可。

Q：能播放但音质很差 / 无法拖动进度条？
A：插件返回的是阿里云盘的原始文件下载直链，音质取决于你上传的文件本身。若无法 seek，通常是阿里云盘 CDN 对 Range 请求的限制。

Q：会不会占用很多流量？
A：不会。插件只在搜索 / 打开榜单 / 播放时按需请求，不会后台预下载。
