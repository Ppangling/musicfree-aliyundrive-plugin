# musicfree-aliyundrive-plugin

> MusicFree 音源插件：把阿里云盘当音乐库来放歌

将你的阿里云盘变成一个私人的音乐备份库。无需在本地存储海量音频文件，只需把音乐上传到阿里云盘指定目录，即可在 MusicFree 中直接搜索、播放和收藏，实现跨设备的云端音乐库体验。

## 这是什么

这是一个 [MusicFree](https://github.com/maotoumao/MusicFree) 的音源插件。MusicFree 本身不内置任何音源，所有搜索、播放、歌单导入等功能均通过插件实现。本插件将阿里云盘作为数据源，让你可以把云盘中的音乐文件当作本地音乐库来使用。

**典型使用场景：**

- 你已经在阿里云盘备份了大量音乐文件，希望在手机上直接流式播放，无需下载到本地。
- 你希望在不同设备（手机、电脑）上共享同一个音乐库，只需要维护云盘中的一份文件。
- 你希望把 MusicFree 的播放记录、收藏等与自建的云盘音乐备份结合起来，减少对第三方音乐平台的依赖。

## 功能特性

- **云盘音乐检索**：在 MusicFree 的搜索框中输入关键词，插件会在你指定的阿里云盘目录中检索匹配的音频文件。
- **在线播放**：直接获取音频文件的播放地址，无需先下载到本地。
- **歌词支持**：如果你的音乐文件旁边存放了同名的 `.lrc` 歌词文件，插件会自动读取并显示。
- **目录递归扫描**：支持递归扫描子目录，便于按歌手或专辑组织音乐文件。
- **本地缓存**：对文件列表和歌词信息进行短期缓存，减少重复请求。

## 安装

### 安装插件

在 MusicFree 中安装本插件，需要使用以下插件源地址：

```text
https://raw.githubusercontent.com/Ppangling/musicfree-aliyundrive-plugin/refs/heads/main/aliyundrive.js
```


**步骤：**

1. 打开 MusicFree，进入「插件管理」页面。
2. 选择「添加插件」→「从网络安装」，粘贴上述 URL。
3. 确认安装后，插件列表中会出现名为 **aliyundrive** 的音源。

> 如果你希望本地安装，也可以直接下载 `aliyundrive.js` 文件，在插件管理页面选择「从本地安装」导入。

### 获取阿里云盘 Token

本插件需要通过阿里云盘的 `refresh_token` 来访问你的云盘文件。推荐使用已有的阿里云盘第三方工具（如 Alist、aliyunpan 等）获取 Token，也可以参考阿里云盘开放平台的开发者文档。

你需要准备以下参数：

| 参数 | 说明 |
|------|------|
| `refresh_token` | 阿里云盘刷新令牌，用于保持登录状态 |
| `device_id` | 设备标识，通常由获取 Token 的工具一并提供 |
| `drive_id` | 云盘 ID，告诉接口你要在哪一块「存储空间」里面操作文件 |
| `parent_file_id` | 存放音乐的根目录 ID，默认为 `root` |

### 配置插件

安装插件后，在 MusicFree 的插件设置中找到 **aliyundrive**，填写从上一节获取的参数。插件支持通过用户变量（User Variables）的方式存储配置，配置项包括：

- `REFRESH_TOKEN`：必填，阿里云盘的刷新令牌。
- `DEVICE_ID`：必填，设备标识。
- `DRIVE_ID`：必填，储存空间编号，盘的ID。
- `PARENT_FILE_ID`：选填，默认为 `root`，即从云盘根目录开始扫描。

> 插件源码中已实现用户变量的读取逻辑，配置会通过 `env.userVariables` 传入插件运行环境。

## 使用方式

配置完成后，在 MusicFree 中搜索歌曲，插件会调用阿里云盘的 API 在你指定的目录中查找匹配的音频文件。支持的音频格式包括：

`mp3`、`flac`、`m4a`、`aac`、`wav`、`ogg`、`ape`、`wma` 等常见格式。

**推荐的文件组织方式：**

```

PARENT_FILE_ID（配置的根目录）
├── 晴天 - 周杰伦 .mp3        ← 直接放在根目录的歌曲，进入「全部音乐」可见
├── 晴天 - 周杰伦.lrc          ← 歌词文件
├── 华语流行/                ← 一级子文件夹，会成为「榜单」之一
│   ├── 江南 - 林俊杰.mp3
│   ├── 江南.lrc
│   └── 浮夸 - 陈奕迅.flac
├── 欧美经典/                ← 另一个「榜单」
│   └── ...
└── 我的收藏/                ← 又一个「榜单」
    └── ...

```

>**命名建议**：采用 `歌名 - 歌手 - 专辑（可选）.扩展名` 格式，短横线两侧要有空格。插件会自动拆分歌名与歌手；不按此格式命名时，整段文件名会作为歌名，歌手显示为「未知歌手」。

>插件会递归扫描 `PARENT_FILE_ID` 下的所有子目录，按文件名匹配歌曲标题和艺术家信息。如果你的文件名格式比较规范（如 `艺术家 - 歌曲名.mp3`），匹配效果会更好。

## 🎤 歌词匹配规则

插件会自动扫描同目录下的 `.lrc` 文件，并按以下优先级匹配：

| 音频文件 | 候选歌词名（优先级从高到低） |
|----------|------------------------------|
| `晴天.flac` | `晴天.lrc` |
| `晴天 - 周杰伦.flac` | `晴天 - 周杰伦.lrc` → `晴天.lrc` |
| `晴天 - 周杰伦 - 叶惠美.flac` | `晴天 - 周杰伦 - 叶惠美.lrc` → `晴天 - 周杰伦.lrc` → `晴天.lrc` |

> 要求：歌词与歌曲必须在**同一文件夹**，去掉扩展名后名称一致（分隔符支持 `-`）。

## 技术说明

本插件遵循 MusicFree 的插件协议，导出标准的 CommonJS 模块，包含 `platform`、`version` 等属性字段，以及 `search`、`getMediaSource` 等核心方法。

**核心实现：**

- 通过阿里云盘 API 的文件列表接口递归获取指定目录下的音频文件。
- 对文件列表和歌词内容进行缓存（`CACHE_TTL` 和 `LRC_CACHE_TTL`），减少 API 调用频率。
- 解析文件名以提取歌曲标题、艺术家、专辑等信息，并转换为 MusicFree 的 `IMusicItem` 数据结构。

**注意事项：**

- 本插件依赖阿里云盘的 `refresh_token`，请妥善保管，不要泄露给他人。
- 如果云盘中的音乐文件过多，首次扫描可能会比较慢，建议合理组织目录结构。
- 插件源码经过压缩混淆处理，如需二次开发，建议参考 MusicFree 官方的[插件开发文档](https://musicfree.catcat.work/) 和[插件模板](https://github.com/maotoumao/MusicFreePluginTemplate)。
